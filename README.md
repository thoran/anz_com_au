# anz_com_au

## Description

Log into ANZ Internet Banking (login.anz.com) and export an account's transactions.

Nothing is implemented yet: this version holds only the name.

## Installation

Add this line to your application's Gemfile:
```ruby
gem 'anz_com_au'
```
And then execute:
```shell
$ bundle
```
Or install it yourself as:
```shell
$ gem install anz_com_au
```
